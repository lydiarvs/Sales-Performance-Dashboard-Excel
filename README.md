# 📊 Sales Performance Dashboard (Microsoft Excel)

## 📌 Overview

This project is an interactive Sales Performance Dashboard built using Microsoft Excel. It analyzes sales data and provides insights into revenue, profit, product performance, regional performance, and salesperson performance through an interactive dashboard.

---

## 🎯 Project Objective

- Analyze sales performance using Excel.
- Track key business metrics with KPI cards.
- Visualize sales trends and profitability.
- Create an interactive dashboard using slicers.

---

## 🚀 Dashboard Features

- 📈 Total Revenue
- 💰 Total Profit
- 📦 Total Orders
- 🛒 Total Quantity Sold
- 📊 Profit Margin (%)
- 📅 Revenue by Month
- 🌍 Profit by Region
- 🥧 Sales by Category
- 🏆 Top 10 Products by Revenue
- 👤 Revenue by Salesperson
- 🎛️ Interactive Slicers (Category, Region, Salesperson)

---

## 🛠️ Tools & Features Used

- Microsoft Excel
- Excel Tables
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Dashboard Design & Data Visualization
